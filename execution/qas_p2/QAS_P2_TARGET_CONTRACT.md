# QAS-P2 Target Contract — Observability Before Prediction

## Constitutional order

[
G_{m OBS}ightarrow G_{m ID}ightarrow G_{m PRED}
ightarrow G_{m CERT}ightarrow KCH.
]

A predictor is inadmissible if its target is neither observed, deterministically
derivable, nor reconstructible from a frozen and independently bound source.

## Historical v3.5 target status

### Eligible from the canonical archive
- post-warper activity;
- support cardinality/fraction;
- scalar support Jaccard;
- scalar retained-energy targets;
- phase/cap events.

### Not eligible as exact coordinate labels
- exact token IDs of the support;
- exact baseline candidate token IDs;
- tokenwise intervention-energy vector;
- mandatory warper-support token IDs;
- coordinate-level necessity;
- minimum support;
- behavioral-equivalence class of supports.

The v3.5 runtime computed exact mask indices transiently, but did not serialize
them into trajectory sketches or summaries.

## QAS-P2 target

QAS-P2 MUST NOT be defined by default as:
`predict the historical heuristic mask exactly`.

The scientific target is a fidelity-qualified support class:

[
[S]_F={S':Phi_F(S')=Phi_F(S)},
]

where (F) is declared before evaluation, for example:
- exact post-warper distribution;
- coupled next-token identity;
- coupled-trajectory identity;
- termination identity;
- task-utility tolerance.

Only after prospective coordinate labels and counterfactual mask tests exist may
one ask whether exact historical masks are unique, minimal, or merely one
representative of a larger equivalence class.

## Prospective instrumentation required

At each audited step persist:
1. exact QAS support token IDs;
2. vocabulary size/tokenizer hash;
3. pre-operator baseline candidate IDs and probabilities;
4. operator/action identity;
5. support-construction parameters;
6. post-warper active-set IDs when allowed by storage;
7. exact fidelity endpoint;
8. hashes and run provenance.

For support prediction research, additionally execute planned ablations/closure
tests on held-out campaigns. Logging a heuristic support does not prove its
necessity or minimality.

## Fail-closed rule

If `G_OBS` fails:
- do not train a supervised predictor for that target;
- do not substitute a plausible synthetic label;
- either choose a coarser observed target or execute a new instrumented campaign.
